# ☕ Hệ Thống Quản Lý Quán Nước

Website quản lý quán nước được xây dựng bằng HTML, CSS và JavaScript.

## 🌐 Demo

🚀 [XEM DEMO HỆ THỐNG QUẢN LÝ QUÁN NƯỚC](https://9huk.github.io/Tu-t/) 🚀
## 📖 Giới Thiệu

Hệ Thống Quản Lý Quán Nước là một website hỗ trợ quản lý toàn bộ hoạt động của quán nước, bao gồm quản lý sản phẩm, khách hàng, nhân viên, đơn hàng, doanh thu và danh mục.

Dự án được xây dựng hoàn toàn bằng **HTML, CSS và JavaScript**, sử dụng **LocalStorage** để lưu trữ dữ liệu trên trình duyệt mà không cần sử dụng cơ sở dữ liệu hoặc Backend.

Mục tiêu của dự án là giúp người quản lý dễ dàng theo dõi hoạt động kinh doanh, tiết kiệm thời gian và nâng cao hiệu quả quản lý.

Đây là đồ án môn học được thực hiện bởi **Nhóm 3**.
